Khu Vực Tích Hợp Ứng Dụng AI Trực Quan

Khi bạn phát triển xong app trên Hugging Face Spaces (ví dụ: Phân tích cảm xúc văn bản hoặc Nhận diện hình ảnh), hãy nhúng thẻ <iframe> vào đây để học sinh tương tác trực tiếp mà không cần chuyển tab.

Hướng dẫn kỹ thuật:

Vào Space của bạn trên Hugging Face -> Nhấp vào icon ... -> Chọn Embed this space -> Copy mã iframe và dán thay thế khu vực này.
